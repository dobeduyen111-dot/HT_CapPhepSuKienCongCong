# Sơ Đồ Thiết Kế Hệ Thống (Diagrams)

Thư mục này chứa toàn bộ các tệp mô hình hóa và sơ đồ thiết kế hệ thống theo phương pháp luận Hướng đối tượng (OOAD/UML):

1. **Tệp thiết kế chính:** SDBC_ViewParty_Diagrams.drawio
   - **Công cụ mở:** Có thể mở và chỉnh sửa trực tiếp bằng phần mềm [Draw.io Desktop](https://www.drawio.com/) hoặc truy cập trực tuyến tại [app.diagrams.net](https://app.diagrams.net/).
   - **Nội dung bao gồm:**
     * Mô hình tổng quan 28 Use Case nghiệp vụ (5 phân hệ vai trò).
     * Sơ đồ phân rã chức năng nghiệp vụ (Tiếp nhận, Thẩm định, Lấy ý kiến liên ngành, Phê duyệt cấp phép).
     * Sơ đồ lớp phân tích (Analysis Class Diagram).
     * Sơ đồ tuần tự (Sequence Diagrams) và Sơ đồ hoạt động (Activity Diagrams) cho các luồng nghiệp vụ trọng tâm.
     * Thiết kế bố cục giao diện người dùng (UI Wireframes / Mockups).
